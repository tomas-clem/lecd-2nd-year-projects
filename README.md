# Data Science & Engineering — 2nd Year Projects

Selected projects from the second year of my degree in Data Science and Engineering (*Licenciatura em Engenharia e Ciência de Dados*) at the University of Coimbra (FCTUC), academic year 2022/23.

| Project | What it does | Stack |
|---|---|---|
| [Googol search engine](googol-search-engine/) | Distributed web search engine: a crawler, index servers and a web interface, connected with Java RMI | Java, RMI, Jsoup, Spring Boot, Thymeleaf |
| [Flight school API](flight-school-api/) | REST API and relational database for managing pilots, aircraft, bookings and flight logs | Python, Flask, PostgreSQL |
| [Rain prediction](rain-prediction-australia/) | Predicts next-day rain in Australia with a decision tree and KNN | Python, pandas, scikit-learn |
| [Vaccination registry](vaccination-registry-data-structures/) | The same registry implemented with six search structures (linear search to AVL tree) and benchmarked | Python |

The first three were group projects developed with Afonso Cordeiro. The vaccination registry was an individual project.

## Notes

- The code is kept as it was submitted, except for the minimal changes needed to build or start each project. These are listed in each README under *Changes from the submitted version*, together with known limitations.
- Code comments, user interface text and reports are in Portuguese.
